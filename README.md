# ЭлектроКонтроль — Android проект

## Что внутри
- Добавление показаний однотарифного электросчётчика.
- Проверка, что новое показание не меньше предыдущего.
- Расчёт расхода и стоимости интервала по текущему тарифу.
- Локальное хранение истории на устройстве.
- Ручное изменение тарифа.

## Сборка APK через GitHub Actions
1. Распакуйте архив.
2. Загрузите **все файлы и папки изнутри** в корень пустого GitHub-репозитория. Важно: включите скрытую папку `.github`.
3. После загрузки откройте вкладку **Actions**.
4. Выберите **Build Android APK** и нажмите **Run workflow**, если сборка не запустилась автоматически.
5. После завершения откройте запуск workflow и скачайте артефакт `ElektroKontrol-debug-apk`.
6. Распакуйте скачанный артефакт — внутри будет `app-debug.apk`.

Это первая сборочная версия. Перед использованием проверьте расчёты на своих показаниях. Настоящие системные уведомления, графики и прогнозы будут добавлены следующими этапами.
